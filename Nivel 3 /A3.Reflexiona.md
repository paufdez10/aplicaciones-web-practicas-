  1. ¿En qué tipo de páginas resulta más útil un índice con bookmarks?

      En páginas largas con muchas secciones, donde hay que hacer mucho
     scroll: manuales, guías, tutoriales, documentación, preguntas
     frecuentes o textos legales.

  2. Al final de cada sección habrá un enlace de vuelta al índice. ¿A qué
     id debe apuntar y dónde tienes que ponerlo?
     
     Debe apuntar al id del índice (por ejemplo id="indice"). Ese id se
     pone en el elemento donde empieza el índice (el título del índice o
     el ``<nav>)``, y el enlace <a href="#indice">Volver al índice</a> se
     coloca al final de cada sección.

  3. ¿Qué pasaría si dos secciones tuvieran el mismo id?
     
     El HTML sería incorrecto, porque cada id debe ser único. El navegador
     saltaría siempre al primer elemento con ese id, y la segunda sección
     quedaría inalcanzable con el enlace. También daría problemas con CSS
     y JavaScript.
