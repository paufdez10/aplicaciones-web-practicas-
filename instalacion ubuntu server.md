# INSTALACION UBUNTU SERVER

- ABRIMOS VIRTUAL BOX

- LE DAMOS A NUEVO

- PONEMOS LA ISO Y CAMBIAMOS EL NOMBRE

- QUITAMOS LA OPCION DE PROCEED WITH ... DE INSTALACION

- SIGUIENTE

- BASE MEMORY 2048 MB

- NUMBERS OF CPU 2

- DISK SIZE 25,00 GB

- FINISH E INICIAMOS UBUNTU

**Si te da error la maquina, la puedes desinstalar y la vuelves a instalar con otra versión y debería irte.**

*Si te va , estos son los pasos ha realizar:*

1. Elige el idioma
2. Eliges el teclado
3. Eliges Ubuntu Server
4. En la configuración de red ,miras que este todo correcto y le das a done
5. En el proxy y mirror lo dejas en blanco y le das a done
6. En el almacenamiento eliges , usar el disco completo
7. En el perfil de usuario pones tu nombre, el nombre del server , contraseña...
8. Le das a activar SSH
9. Snaps destacados, ninguno
10. Y final de la instalación
